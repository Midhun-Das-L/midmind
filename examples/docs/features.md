# Features

Offline mode: notes are stored on your device and sync automatically when you are
back online. Conflicts are resolved by keeping both versions.

Export: you can export all notes as Markdown, PDF or a JSON archive from
Settings > Data > Export. Exports include attachments up to 2 GB in total.

Sharing: any note can be shared with a public read-only link, or with teammates who
can edit it. Shared links can be revoked at any time.
